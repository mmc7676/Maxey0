# Maxey0-SuperSpace MCP App

React/TypeScript source for the Maxey0 MCP Apps extension surface.

The app is intentionally a **SuperSpace application**, not the definition of SuperSpace itself. It visualizes the Maxey0 enforceable address, semantic gate state, host-visible context, and request result.

Build with Node 20+ and the current MCP Apps packages. The server-side registration uses `_meta.ui.resourceUri` and a `ui://` resource, as required by the MCP Apps extension.
