# SCW Default Deployer

1. Create SCW0 before the task/loop executes.
2. Bind the task to a semantic address and explicit constitution.
3. Spawn child SCWs for independent agents or isolated roles.
4. Bind each child agent to only its declared context view.
5. Route external MCP capabilities through Maxey0 gates.
6. Record lifecycle, epoch, state, provenance, tool calls, admissions, and outcomes.
7. Seal the SCW and retain a replay recipe.

SCW is the execution boundary. MCP is the capability interoperability boundary. A2A is the agent/task interoperability boundary. The host model/harness remains external.
