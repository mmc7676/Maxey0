# SCW0 — Context Extraction and Synthesis

SCW0 is the source-of-truth build input for the final public package. It excludes the user's explicitly excluded video-game and dream discussions.

## Scope
- Current Maxey0 architecture and terminology.
- Maxey0 / FullStack repository material available in Library.
- Prior generated architecture documents and experiment artifacts that remain retrievable.
- MCP `2026-07-28` protocol requirements verified against the official MCP release.

## Important provenance rule
SCW0 distinguishes user requirements, prior repository artifacts, source-derived facts, and implementation inference. It does not claim that platform-private ChatGPT context is directly observable. Host-visible context must be supplied through an integration surface.
