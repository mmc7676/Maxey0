Maxey0-SuperSpace

Governed context and execution for agents

An explicit window address space, a gate at every tool call and every model egress, and a hash-chained record of both that a third party can verify without trusting the system that produced it.

Observability-first in a structural sense: there is no code path that reaches outside a window without being admitted and recorded, because the recording happens before the reach and a refusal is written as evidence rather than as silence.

What it does

One window address space. An SCW is an explicit, enforceable application-level address — not a session, not a process. It is carried between stateless requests as a handle, which is the mechanism MCP 2026-07-28 provides for exactly this.

A gate at every boundary. Tool calls and model egress are admitted by the same provider. A deployment that names a semantic provider this build does not implement fails closed: a request for stricter gating is never answered with less.

A record that is evidence. Every decision is appended to a hash-chained log whose digest covers the entry before it, so a removed record is detectable rather than invisible. The verifier is published and needs no knowledge of how decisions are made — maxey0-ss.evidence.verify checks records you hold against a chain you did not have to trust.

Egress is observed. A prompt leaving for api.anthropic.com is a larger event than a read between two windows, and it is recorded as one — with the prompt digested, never stored, because the containment record is published and a published record carrying prompts would be a published record of user data.

Install

/plugin marketplace add mmc7676/Maxey0
/plugin install maxey0@maxey0

Eighteen installable targets across nine platforms — Claude Code, Claude Desktop, Claude connectors, ChatGPT, Codex, MCP over stdio and Streamable HTTP, and A2A. Every manifest is generated from one declaration, so the plugin id, the package name and the MCP server name cannot disagree.

Before you expose it. Set MAXEY0_PUBLIC=1 on anything internet-reachable. Without it, and with authorization disabled, every caller resolves to admin. maxey0-ss.auth.manifest reports admin_open: true when you are in that state, with a warning naming the fix.
