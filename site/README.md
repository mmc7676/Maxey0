# maxey0.com distribution surface

maxey0.com is an appropriate distribution channel because it can be the canonical installation and documentation surface for the open core, harness adapters, plugin bundles, MCP delivery server, and hosted A2A endpoint.

This repository contains only a static site scaffold. Domain registration, DNS, TLS, hosting, CI/CD, authentication, billing, and production API hosting are deployment concerns and are intentionally not represented as completed by this source tree.
